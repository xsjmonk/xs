# Codex XS Routing

For every XS-related task, automatically apply the `xs-language` skill before
reading, explaining, writing, reviewing, or debugging XS code. The user does
not need to invoke a command manually.

The canonical skill is `xs-language/SKILL.md`. It is independent of other
repositories and must use only this repository's `Interpreter.ATG`, `readme.md`,
`readme_new.md`, `ConsoleExtension.md`, and `Scripts/` sources.

Do not duplicate the skill content in this file or in another repository.
